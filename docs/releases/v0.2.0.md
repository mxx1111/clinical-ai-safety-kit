# Clinical AI Safety Kit v0.2.0

Clinical AI Safety Kit v0.2.0 adds reproducible engineering evidence and an optional medical-imaging workflow integration while preserving the existing deterministic safety rules and REST contracts.

## Highlights

- Four bilingual deterministic text-safety rules for emergency escalation, unsupported medication dosage, sensitive identifier echo, and unjustified diagnostic certainty.
- Privacy-safe HL7® FHIR® R4 Bundle structure validation with stable `MAG-*` result and error codes.
- A versioned 16-case bilingual synthetic benchmark that fails on status or exact rule-code mismatches.
- Deterministic JSON and Markdown benchmark reports plus a CycloneDX 1.6 runtime SBOM.
- CI evidence artifacts containing the benchmark reports and SBOM.
- An optional fail-closed MONAI Deploy App SDK text gate before a downstream DICOM Text SR writer.
- English and Simplified Chinese documentation.

## Verify locally

```bash
./mvnw verify
python3 -m unittest discover -s integrations/monai-deploy/tests -p 'test_*.py'
python3 scripts/verify_agent_receipt.py --all
```

## Important boundaries

- The benchmark uses intentionally narrow synthetic examples. Its exact-match result is regression evidence, not clinical validation or a model-quality comparison.
- The MONAI integration evaluates generated narrative text only; it does not evaluate medical images, segmentations, or model accuracy.
- The toolkit is not a medical device and does not provide diagnosis, treatment, emergency, or professional medical advice.
- Never submit real patient data, PHI, identifiers, production logs, secrets, or private prompts.
- Clinical AI Safety Kit is independent and is not affiliated with or endorsed by HL7, Project MONAI, NVIDIA, or their contributors.
